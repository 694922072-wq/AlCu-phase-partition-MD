# Model name mapping

Historical internal label:  
`M4_SYM_RATIO`

Public manuscript label:  
`M4_RATIO`

All public directory names and public-facing metadata use `M4_RATIO`. The historical label is retained only inside unmodified legacy source-code or LAMMPS-input text where changing it could break the archived workflow. The scientific data bytes, seeds, atom counts, and results were not changed.
